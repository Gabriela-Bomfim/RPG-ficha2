# 📁 Ficha de Herói - Parte 2

Este é meu projeto final desenvolvido durante o curso **Tecnologia Web - Engenharia da Computação (Front-End)**. Trata-se de um site de uma ficha de personagem de RPG, e formas de contato.

---

## 📌 Sobre o Projeto

Este site foi criado com foco em aplicar os conhecimentos de **HTML**, **CSS**, **Flexbox**, **responsividade** e **JavaScript** e **publicação com GitHub Pages**.

---
## Funcionalidades

O projeto foi estruturado para exibir:
**Sobre o Herói**- Dados da trajetória e imagem de destaque;
**Atributos & Habilidades**- Barra de progresso e lista de habilidades;
**Inventário**- Itens em grade, com tipo, raridade e descrição;
**Contato com a Guilda**- Links úteis para interação;



---
## 🧰 Tecnologias Utilizadas

- HTML5 (Estruturação semântica)
- CSS3 + Flexbox e Grid
- JavaScript (DOM, eventos, arrays de objetos, localStorage)
- Google Fonts (Fontes Cinzel e Inter)
- Font Awesome
- Git + GitHub
- GitHub Pages (para publicação)

---

## ⚡ Funcionalidades em JavaScript (Parte 2)

- Menu hambúrguer em telas pequenas (fecha no ✕, ao escolher um link ou com Esc)
- Botão "Ver história completa" / "Ver menos"
- Experiência e nível: cada missão dá 25 XP; a cada 100 XP há "Nível up!" e um atributo ganha +1
- Inventário gerado a partir de um array com 6 itens, com filtros por tipo e raridade
- Favoritar itens e contador de itens conquistados
- Formulário validado (campos obrigatórios e formato do e-mail). O envio é simulado
- Modo noturno, saudação por horário e rolagem suave
- **Pesquisa complementar:** `localStorage` guarda nível, XP, atributos, favoritos e tema

## 🧠 Decisões de UI/UX

- **Visibilidade do estado:** ícone ☰/✕, filtro ativo destacado, barra de XP e contador
- **Feedback imediato:** mensagens na tela ao ganhar XP, filtrar e enviar o formulário; o botão de favorito muda na hora
- **Prevenção de erros:** campos obrigatórios marcados com *, aviso ao sair do campo e confirmação antes de reiniciar o progresso
- **Controle e liberdade:** menu, história, filtros, favoritos e tema podem ser desfeitos sem recarregar
- **Consistência:** os novos estados usam as cores, bordas e transições da Parte 1
- **Acessibilidade:** foco visível, atributos `aria` e respeito à opção de reduzir movimento

## ▶️ Como executar

Extraia o .zip e abra o `index.html` no navegador. As fontes e os ícones precisam de internet.
